# 増殖ゲート — Gate Runner

ゲートをくぐって軍勢を増やし、武器を鍛え、立ちはだかる赤軍を薙ぎ倒す疑似3Dランナー。全10ステージ。

**▶ [ブラウザで遊ぶ](https://machino-ai.jp/gate-runner/)**

広告でよく見るあの系統（Count Masters / Join Clash 系）を、実際に遊べる形にしたもの。
「広告では面白そうなのに本編は別物」という業界の慣習に対して、**広告に出そうな遊びをそのまま中身にしたらどうなるか**を試した習作です。

## 遊び方

| 操作 | |
|---|---|
| ドラッグ | 隊列を左右に動かす |
| ← → / A D | 同上 |

前進は自動。ゲートは通過した瞬間に効果が適用されます。

### ゲートの色

| 色 | 意味 |
|---|---|
| 緑 `+40` `×2` | 兵力が増える |
| 赤 `−25` `÷2` | 兵力が減る |
| 金 剣アイコン `+1` | 武器が1段上がる |

**戦闘力 = 兵力 × 武器倍率**。武器は7段階（素手 ×1.00 → 棍棒 → 短剣 → 長剣 → 槍 → 戦斧 → 雷槌 ×6.00）。

回転する刃は、当たった兵だけを個別に削ります。隙間を抜けてください。

## 設計メモ

### 選択を「色で答えを教えない」ようにする

このジャンルの面白さの芯は、**ゲートの選択が毎回計算問題になっている**ことだと考えました。
そこで色分けは「緑＝量が増える／赤＝量が減る／金＝質が上がる」という**軸の区別だけ**に留め、どちらが得かは教えません。

さらに `+N` の生成幅を「×2 の前後」に寄せてあるため、`+180` と `×2` は常に僅差になります。
兵力20なら `+60` が正解、兵力300なら `×2` が正解、と局面で答えがひっくり返る。惰性では選べません。

ゲートの約半分は**両方とも緑**です。「損しない選択」ではなく「より得な選択」を毎回させるためです。

### 戦闘はランチェスターの二乗則

単純な引き算ではなく、**損害が相手の総戦闘力に比例する**モデルにしています。

```
敵の減少速度 ∝ 自軍の兵力 × 自軍の武器倍率
自軍の減少速度 ∝ 敵の兵力 × 敵の武器倍率
```

結果として、数で押しても質で押しても勝てるが、**質で勝つほうが損害が軽い**。
これが武器ゲートを選ぶ動機になります。

敵の規模は `自軍兵力 × √(自軍倍率 ÷ 敵倍率) × 係数` で生成しているので、
**武器を伸ばすと敵の数も増えて釣り合います**。武器ばかり選んで兵を疎かにすると普通に押し潰されます。

### 難易度は生成時にシミュレーションで検証した

ステージは「上手いプレイヤーが毎回最適な選択をした場合の見込み兵力」を追いながら組み立てています。

ただし最初の調整では、**最適プレイでもステージ6で全滅する**構成が生まれていました。原因は2つ：

1. 刃を出しすぎて、1ステージに9枚 → `0.8^9 = 13%` まで削られる想定になり、生成側の下限値とズレて詰み構成ができた
2. ボスが想定兵力の最大96%で生成されていた → 二乗則では余裕が4%しかなく、刃で少し削られた時点で数学的に勝てない

刃を「3ゲートに1枚まで」に制限し、ボスの上限を76%に下げて余白を作りました。
`FLOOR` と `makeSquad` の係数にはその理由をコメントで残してあります。

調整後、10ステージ通しを600回ずつ試行した結果：

| ゲート正答率 | 完全制覇率 | 平均到達ステージ |
|---|---|---|
| 100% | 99.0% | 9.9 |
| 95% | 36.0% | 6.7 |
| 90% | 12.0% | 4.9 |
| 80% | 1.3% | 2.9 |

難易度は**速度と刃（反射神経）**で出し、算数の失敗が即死にはならない方向に寄せています。
ステージ10ではゲート間が0.7〜1.0秒しかないので、遠くのゲートを先読みする必要があります。

## 技術

**外部ライブラリなし。1ファイル。** 読み込んでいるのは Google Fonts だけです。

- **疑似3D**: ゲームエンジンを使わず、Canvas 2D に焦点距離700の透視投影を自前で実装。道・石柱・遠景の岩山・ゲート・兵士まで、すべてこの座標変換の上に乗っています
- **群衆**: 黄金角（137.5°）を使ったひまわり配置で隊列を組成。兵力の増減に応じて湧いたり消えたりしながら、隊形が自然に流れます（最大420体）
- **武器**: 画像素材を使わず、7種すべてを図形で描画
- **音**: WebAudio でその場で合成（音声ファイルなし）

